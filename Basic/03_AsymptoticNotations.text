Asymptotic Notations : Big O, Big Omega and Big Theta

Use these Notations to compare algorithms with each other.

Big O --> A function f(n) is said to be O(gn) iff there exist constant c & a constant n such that **0<=f(n)<=cg(n) for all n>=n0**
mathematically the f(n) can be any function but during algorithm analysis it is the time and n is the size of input

example = n^3+1
g(n) = n^4 check
0<=n^3+1<+n^4 {c=1}

basically mean cgn>fn  {upper bound}

-----> example - Prove 3n+2 = O(n)----->
given :- f(n) = 3n+2, and g(n) = n
Goal :- Find positive constants c and n0 such that 3n+2<=c*n for all n>=n0.
Let's choose a constant c = 5.
Now , substitue c = 5 into the inequality: 3n+2<=5n.
Rearranging terms :- 2<=5-3n --> 2<=2n --> 1<=n.
so the inequality holds for all n>=1.
Therefore, choosing c = 5 and n0 = 1 proves that 3n+2 = O(n).

Big Omega --> 0<=cgn<=fn for all n>=n0
basically mean fn>cgn  {lower bound}

Big Theta --> always report this.  {tight bound}
A function is said to be theta(gn) iff there exist  constant c & a constant n such that 
0<=f(n)<=c1gn
0<=c2gn<=f(n)
